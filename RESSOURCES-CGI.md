# 🔗 Express Diagnostic — CGI resources linked to the roadmap

Each recommendation shown in the Express Diagnostic roadmap (`express-diagnostic.html`) links to the closest CGI blog article, offering or news item, regardless of language or region. The wording of each recommendation invites the reader to go further with that resource. A recommendation without a matching resource is shown as is.

The mapping lives in the `ROADMAP_ITEMS` array of `express-diagnostic.html`. This file documents it for maintenance: when a CGI page moves or a closer article is published, update both.

All resources are in English. The region column indicates the CGI site that hosts the page.
